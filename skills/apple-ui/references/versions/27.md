# UI craft: what 27 changed (2026)

Material and motion deltas: liquid-glass `versions/27.md`. Here: what changes how screens are built.

| Area | 26 | 27 | Do |
|---|---|---|---|
| Edge of glass controls | soft cloud, no outline | dark hairline + top/bottom rim | controls read on white without a shadow; drop extra borders |
| Panels | translucent | near-opaque (70 % white / dark face) | text on panels needs no extra scrim |
| Shadows | one for all sizes | none under controls, deep under panels | shadow = "floats above the screen", use for panels only |
| Press feedback | big swell, blobs fuse | small, fast, no fusing | no playful blobbing on taps |
| Bar mode change | 0.4 s, title removed | ≤ 0.18 s, **title stays** | keep title slots fixed across modes |
| Tinted control | translucent colour | near-opaque colour | treat as a solid-colour button with a glass rim |
| Inactive window | (unspecified) | glass off, flat fills | design the inactive state |
| Transparency setting | Clear / Tinted switch (26.1) | slider, ultra clear → fully tinted | test both ends |
| Scroll under bars | per-bar effects | uniform toolbar treatment | use scroll edge effect APIs, no custom gradients |
| Icons | glass slab over art | glass at edges inside art, fixed highlights | flat layered artwork; let the system finish it |
| macOS window radius | 26 | 16 | concentric radii recomputed |
| macOS toolbar controls | 24 | 24 and XL 36 | larger toolbar targets available |
| macOS alert | r 26 | r 34 | |
| iPhone tab bar | tab 102 wide | 92 wide; search role and prominent tab as types | |
| Devices | iPhone, iPad | + foldable "iPhone Duo" in Apple's kit (inner / outer display, vertical tab bar) | size classes; bars may sit on the leading edge |
| App close | static wallpaper | wallpaper zoom-out restored (27.3) | depth cue on return; off under Reduce Motion |

System colours unchanged from 26: blue `#0088FF` / `#0091FF`, red `#FF383C` / `#FF4245`.

Direction: every change bought legibility or hierarchy, paid for with spectacle.
