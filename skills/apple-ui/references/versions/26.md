# UI craft: what 26 introduced (2025)

Superseded where `27.md` lists a change. Kept for matching 26 screens.

- **Liquid Glass** replaces the flat translucent bars of 7–18: floating capsule toolbars and tab bars, glass menus and partial sheets, content extending under bars with a scroll edge effect.
- One version number across platforms (iOS, iPadOS, macOS, watchOS, tvOS, visionOS 26).
- System colours shifted: blue `#007AFF` → `#0088FF` (dark `#0A84FF` → `#0091FF`), red `#FF3B30` → `#FF383C` (dark `#FF453A` → `#FF4245`).
- Concentric corners as a rule (`ConcentricRectangle`, container-relative shapes).
- Tab bar: floating, minimises on scroll, separate search button; iPad tab bar ↔ sidebar.
- Toolbars: items grouped into shared glass capsules; spacers split groups.
- Sheets: partial detents inset and glass; full height opaque.
- macOS: window radius 26; sidebars and toolbars as glass over content; menu bar transparent.
- Icons: layered Icon Composer format; default, dark, clear, tinted appearances.
- 26.1: Liquid Glass setting Clear | Tinted.
- Look of 26 glass: no outline, one shadow for every size, strong top-left highlight, big press swell with liquid fusing.
