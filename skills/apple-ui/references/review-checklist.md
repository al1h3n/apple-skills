# Review checklist

## Focus
- [ ] The screen's job fits in one sentence; one primary action, visibly first in a squint test.
- [ ] No shape exists only to decorate (no box per row, pill per value, circle per icon).
- [ ] Long lists use "More…"; long text is folded; credits are folded except required ones.

## Type
- [ ] Every size is on the ramp (HIG for app, modular scale for marketing); ≤ 3 weights.
- [ ] Secondary text uses the secondary colour; line length 45–75 characters.
- [ ] No widows/orphans in display headlines; truncation with an ellipsis where needed.

## Layout
- [ ] 8 pt rhythm; consistent margins; few alignment edges.
- [ ] Targets ≥ 44 pt (touch); primary actions in thumb reach on phones.
- [ ] Concentric continuous corners; hairlines inset to text.
- [ ] No visible scrollbars in panels; overlay indicator while scrolling.

## Colour and material
- [ ] One accent; semantic colours consistent; contrast ≥ 4.5 : 1.
- [ ] Light and dark both designed; glass on and off both designed.
- [ ] Glass only on the functional layer; never glass on glass; Clear only over imagery.

## States
- [ ] Default, hover, pressed, focus, disabled.
- [ ] Loading (skeletons shaped like the result), empty (what appears + one action), error
      (what happened + what to do), offline.
- [ ] Long names, big numbers, small/large Dynamic Type, right-to-left if relevant.

## Motion
- [ ] Every transition grows from its source; springs, not linear easing.
- [ ] Reduce Motion version exists; nothing loops faster than every 3 s.

## Words
- [ ] Titles ≤ 4 words, descriptions one line, buttons are verbs with a result.
- [ ] No jargon or source names in descriptions; numbers where they help.

## Legal
- [ ] Shipped fonts are licensed for the platform (no embedded SF on web/Android/Windows).
- [ ] Required attributions visible (map data, imagery, licence-required credits).
- [ ] Real owner name in the footer; no placeholder handles.
