# iOS / iPadOS / macOS 27 (2026)

Current. Everything in the other reference files describes this version. This file = what changed from 26 and where the proof is.

## 1. Apple's words [Apple, WWDC26 keynote + Platforms State of the Union]

- Material "more effectively diffuses complex content, improving readability throughout the system".
- "A darkened edge around Liquid Glass elements"; "brighter specular highlights".
- "A uniform toolbar now appears across the top" where content scrolls under bars.
- **Transparency slider**, Settings → Appearance, "from ultra clear to fully tinted". Replaces the 26.1 Clear | Tinted switch. Tinted end "a lot more pronounced".
- Apps already on Liquid Glass get most of it without a rebuild.
- Icons: sharper, multi-layer glass, refraction "selectively applied"; highlights fixed (no tilt shimmer).
- macOS 27: sidebar refinements, window corner radius updated.
- 27 beta 3: depth effect in Notification Center (wallpaper subject above the Home Screen).
- 27.3 beta 1: wallpaper zoom-out on app close restored (absent in 26).

Apple's text says nothing about motion. Motion rules rest on measurement.

## 2. Material, 26 → 27 [Kit]

| | 26 | 27 |
|---|---|---|
| Refraction / depth | 1.0 / 16 | 0.7 / 30 (weaker, wider band) |
| Dispersion | 0 (1.0 on Dock) | 0.2 everywhere; 0 on pressed lens |
| Splay | 0.06 | 0.2 |
| Built-in light | 315°, 0.8 | 0°, 0.25 + painted top/bottom rims |
| Outer hairline | none | burn 0.5 pt, stronger at sides |
| Frost small / medium / large | 7 / 12 / 14 | 6 / 16 / 16 |
| Frost Clear / Dock / keyboard | 5 / 7 / 40 | 6 / 3 / 8 |
| macOS menu / popover / notification frost | 12 / 14 / 12 | 25 / 26 / 25 |
| Panel fill, light | `#262626` Color Dodge + `#F5F5F5@60%` | `#FFFFFF@70%` Lighten + `#BFBFBF@10%` Darken |
| Tinted: white under accent | 75 % | 94 % |
| Shadow | one for all: (0, 8) blur 40, 12 % | control (0, 8) blur 15, 2 %; panel (0, 8) blur 48, 25 % |
| Inactive | none | glass removed, flat fill |
| Pressed knob lens | not in the iOS kit | frost 0, refr 0.8, depth 7, light 0 |

On device [M2][M3][M5]: Clear frost σ 4 pt → 0.8 pt; face contrast ×0.79 / +46 → ×0.90 / +26; refraction band visible (14 pt widget, 3–4 pt icon); rim peak 182 → 220; Regular in bars more opaque over media, grey hairline on white; lens hairline neutral, no rainbow.

## 3. Motion, 26 → 27 [M3][M4][M5]

| | 26 | 27 |
|---|---|---|
| Press growth (44 pt button) | ×1.34 (+15 pt) | ×1.08–1.15 (+4–6 pt) |
| Time to peak | 100 ms | 35–65 ms |
| Press light | blown to white, glyph gone | bright, glyph readable; glow-out τ 90 ms |
| Press fuses neighbours | yes, liquid neck | no |
| Bar mode change | 0.40 s; blobs bud and merge | 0.15–0.18 s; frame-to-frame morph |
| Title on mode change | removed | stays in place |
| Bar glyphs | blur 130–170 ms out, same in | 50 ms out, 70 ms in |
| Banner arrival | 0.6 s, uniform scale, τ 150 ms | 0.1 s drop + spring 0.42 s bounce 0.2; width leads |
| Switch tap | 0.42 s; rainbow rim; grey ring first | 0.38 s; neutral hairline; straight to frost |
| Drag | stretch up to 10 % | none; lift only |
| App close | no wallpaper motion | wallpaper zoom 1.10 → 1 (27.3) |

## 4. Components, 26 → 27 [Kit]

- iPhone tab bar: tab 102 → 92 wide; "Separate Search" → types Default / Search Role / Prominent Tab.
- Switch knob 39 → 38; Pressed variants added (switch, slider).
- macOS window r 26 → **16**; alert r 26 → 34; notification 344 × 72 r 16 → 344 × 77 r 20; menu r 13 → 12; toolbar controls gain XL (36).
- New: iPhone Duo (foldable: inner/outer display, vertical tab bar, per-corner radii), empty states, Face ID, colour picker, date pickers, accessory bars, activity view, `Active` state on all glass.

## 6. Reading

Legibility first (hairline, opaque panels, stronger tint, flat inactive), then hierarchy (two shadow classes, frost by role), then calm (weak fixed light, constant faint dispersion, small fast press). Nothing moved the other way.
