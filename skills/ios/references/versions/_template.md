# iOS / iPadOS NN (YEAR)

Adding a version:
1. Copy to `NN.md`, fill the table. Left column = previous OS, right = NN.
2. Update the current files (`components.md`, `navigation.md`, `dynamic-type.md`, `gestures-and-motion.md`, `widgets-and-system.md`, `SKILL.md` numbers) to NN. Move what NN replaced into the previous version's file.
3. Do the same in liquid-glass (`versions/_template.md`) and apple-ui (`versions/NN.md`). Material and motion numbers live there, not here.

Sources to read first: the new "iOS and iPadOS NN" Figma library (dump by key, diff against the previous kit), HIG change log, keynote + State of the Union, SDK diff, a recording of the same situations on a device.
