# iOS / iPadOS 26 (2025)

Superseded where `27.md` lists a change. For matching 26 screens.

- First Liquid Glass release. Bars float as glass capsules; content runs under them; scroll edge effect replaces bar backgrounds.
- Tab bar: floating, minimises on scroll, optional separate search button, bottom accessory (mini player). iPad: top tab bar ↔ sidebar.
- Toolbars: items share glass capsules; `ToolbarSpacer` splits groups; large titles collapse into the bar.
- Sheets: partial detents inset with glass, r 38; full height opaque.
- Search moves to the bottom on iPhone.
- Menus and context menus as glass panels (r 34); action sheets anchored to the control that asked.
- Controls: switch 64 × 28 (knob 39 × 24), slider knob 38 × 24 turning into a lens while dragged; segmented control stays a fill.
- Control Center and Lock Screen buttons in Clear glass; Lock Screen clock as glass text, resizable.
- Icons: layered, with default / dark / clear / tinted appearances; highlights follow device tilt.
- iPadOS: windowing with close / minimise / full-screen controls, menu bar, resizable windows.
- 26.1: Settings → Display & Brightness → Liquid Glass → Clear | Tinted.
- Motion character: big press swell (×1.34), liquid fusing of neighbouring buttons, 0.4 s bar transitions.
- Reference canvas 402 × 874 (iPhone 16 Pro / 17 Pro).
